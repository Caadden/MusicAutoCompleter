# Music Search Autocompleter
### By: Team Rocket

#### To run the program:
- Download all code files (.cpp &.h) and compile as normal.
- The "spotify-tracks-dataset.csv" file must be placed one level **ABOVE** the .exe file, and named exactly as mentioned.
  - If a change in location or filename is desired, then the input to the "csvParse" function must be changed in main (line 102).
